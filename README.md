# 金沙遗址博物馆传播专题平台

32:9 静态可视化大屏原型，基于“传播”表格中的指标层级制作。页面固定为 `2560 x 720` 逻辑画布，内容使用 mock 数据；图表用于平台互动、年龄画像和舆情情绪，其余信息使用数字卡片、话题排行、媒体报道列表、标签和预警台账展示。

## 运行

当前目录启动静态服务：

```bash
python3 -m http.server 4173
```

浏览器打开：

```text
http://localhost:4173/
```

## 文件

- `index.html`: 传播专题大屏结构
- `styles.css`: 32:9 固定画布、传播态势视觉、面板样式
- `app.js`: mock 数据、列表渲染、ECharts 配置
- `assets/ruins-panorama.png`: 中央数字孪生传播区背景
